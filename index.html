The Principle of Duality

The Principle of Duality states that any true identity in a formal algebraic structure (such as Boolean algebra, set theory, or order theory) remains valid when operators and identities are systematically swapped: AND (·) ↔ OR (+) and 0 ↔ 1.

Core Concepts & Theory

Fundamental rules of dual transformations across Boolean algebra, set theory, posets, and LP

01

Boolean Algebra Duality

(·) ↔ (+),   0 ↔ 1

Swap all AND operators with OR operators, and all identity constants 0 with 1, keeping literals (variables) unchanged.

02

Set Theoretic Duality

(∩) ↔ (∪),   ∅ ↔ U

Swap set intersections with unions, and the empty set ∅ with the universal set U.

03

Posets & Order Theory

(P, ≤) ↔ (P, ≥)

Inverting partial order binary relations converts meets (GLB ∧) into joins (LUB ∨) in lattice structures.

04

Self-Dual Functions

f(x₁, ..., xₙ) = fᴰ(x₁, ..., xₙ)

Functions identical to their duals (e.g., Majority function AB + BC + AC). Satisfies fᴰ(x) = ¬f(¬x).

Worked Examples

Example 1

Distributive Law Duality

Fundamental Boolean Algebra Axiom

Primal: A · (B + C) = (A · B) + (A · C)

Dual: A + (B · C) = (A + B) · (A + C)

Transformation:

Swapped outer AND for OR, inner OR for AND, and expanded terms.

Example 2

Absorption Law Duality

Term Simplification Theorem

Primal: A + (A · B) = A

Dual: A · (A + B) = A

Transformation:

Swapped outer OR (+) for AND (·), and inner AND (·) for OR (+).

Example 3

Consensus Theorem Duality

Redundant Clause Elimination

Primal: A·B + A'·C + B·C = A·B + A'·C

Dual: (A+B) · (A'+C) · (B+C) = (A+B) · (A'+C)

Transformation:

Converts product-of-sums into sum-of-products dual representation.
